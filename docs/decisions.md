# 決策紀錄

需求方(學務處)與系統管理端拍板的規則。**這裡記「為什麼系統是這樣」,不記進度**;
進度看 [`HANDOFF.md`](HANDOFF.md),行為細節看 [`spec/`](spec/)。

一條決策落地後,對應的 `ISS-` / `GAP-` / `DEC-` 編號就從 `issues.md` / `gaps.md` 移除,
但本檔的條目**永久保留** —— 後人問「為什麼不能改成 X」時,答案在這裡。
