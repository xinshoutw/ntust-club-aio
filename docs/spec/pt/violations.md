# 違規紀錄查詢

`/pt/violations` · `staff` · `features/pt/PtViolationsPage.tsx`

## 用途

工讀生查全校違規紀錄。唯讀。

## 資料來源

`GET /staff/violations?sort&page&page_size`(每頁 20)。列表形狀、排序白名單與行政端 `/admin/violations` 共用同一份實作。

## 畫面

表格:發生日、社團、地點、違規項目(下方顯示其他說明)、填寫人、銷案期限、狀態。除「社團」外皆可多鍵排序(伺服器端)。

## 規則

- 預設排序:未銷案在前,組內依發生日升冪(與行政端、社團端三方一致)
- 可看**全校**所有社團的紀錄,不限自己開立的

## 未完成 / 問題

- 沒有社團或狀態篩選,也不能只看自己開立的;紀錄一多就只能翻頁
- 「社團」欄不在後端排序白名單內,無法依社團排序
