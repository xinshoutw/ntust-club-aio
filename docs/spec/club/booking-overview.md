# 借用總覽

`/bookings` · `club` · `features/bookings/BookingOverviewPage.tsx`

## 用途

看場況、看自己所有進行中的借用(三類合一)、取消借用、從空格直接跳去申請。

## 資料來源

| 區塊 | 端點 |
|---|---|
| 場地主檔 | `GET /club/venues` |
| 單日場況 | `GET /club/bookings/availability?date=` |
| 單一場地多日場況 | `GET /club/bookings/availability-range?start&end&venue`(上限 31 天) |
| 正在借用(三類) | `GET /club/{room-bookings,venue-bookings,equipment-loans}?active=true` |
| 最近歸還 | `GET /club/equipment-loans?status=returned`(伺服器分頁) |
| 取消 | `POST /club/{…}/{id}/cancel` |

## 畫面

**場地借用情形**(色格圖)— 兩種檢視:

1. 單日全場地:列 = 場地、欄 = 14 節次。日期切換鈕(前後一天/一週/今天)+ 日期選擇器,**不可看過去**。
2. 單一場地 15 天:點場地名稱進入,以當時檢視日為中心 −7~+7,起始日不早於今天。

格子狀態:可借(淺灰)/ 審核中(橘)/ 臨時借用(粉)/ 固定借用(深灰)/ 我的借用(綠)/ 不開放(透明無框)。可借格可點,直接帶場地+日期+節次跳到臨時場地借用頁。被佔用格 hover 顯示借用社團名。

**正在借用** — 固定場地 / 臨時場地 / 器材三類混在同一張表(類別、內容、時間、狀態、動作),不分頁、全部列出。

**最近歸還** — 已歸還的器材借用,伺服器端分頁,每頁 10 筆。

## 規則

- 場況圖的格子權重:`blocked` > `mine` > `temp`/`fixed` > `pending`;審核中(含本社自己的)一律顯示「審核中」
- 固定借用只在其目標學期起訖區間內佔格,學期結束即釋出
- 取消條件三類不同:
  - 固定場地、器材 — 審核中隨時可取消;已核准僅開始日**之前**可取消
  - 臨時場地 — 審核中與已核准一致,以**最早節次的起始時刻**為界
