# 稽核紀錄

`/admin/audit` · `admin`(**僅 super**) · `features/admin/AuditPage.tsx`

> 側欄沒有這一項,入口只有頂欄帳號選單的「稽核紀錄」。

## 用途

高風險操作的軌跡查詢。唯讀。

## 資料來源

`GET /admin/audit?user_id&role&action&date_from&date_to&page&page_size`(每頁 20)

篩選選項另走 `GET /admin/audit/options`(整張表的操作者與動作,不是已載入的那幾頁)

## 畫面

頁首右側是日期區間選擇(含頭含尾,以台北日界切)與「匯出 CSV」(依當前篩選逐頁抓完整結果,不是只匯出這一頁)。

表格:時間、操作者、角色、動作、內容。操作者 / 角色 / 動作三個漏斗篩選 —— 後端是單值參數,所以漏斗是**單選**(點另一項即切換、再點同一項取消)。動作顯示詞對照不到時直接顯示原始鍵。

## 規則

- 依時間降冪,`id` 降冪 tiebreak
- 記錄範圍:簽核、帳號與權限異動、密碼重設、停權、社團主檔異動、成員名冊增刪改與匯入、設定變更、規則增刪、刪除活動草稿、檔案刪除(報修、評鑑、活動照片與附件)、評分與行政分調整等
- 帳號刪除後稽核仍保留(`user_id` ON DELETE SET NULL,操作者顯示為空)
