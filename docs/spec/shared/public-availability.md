# 借用情形(公開)

`/availability` · 免登入 · `features/public/PublicAvailabilityPage.tsx`

## 用途

免登入就看得到全校的借用情形。借用要先登入,這裡只給看。

**不再是首頁** —— 未登入的 `/` 已改成社團導覽([club-directory.md](club-directory.md)),
這一頁由 topbar 的「借用狀態」進來。

## 資料來源

| 區塊 | 端點 |
|---|---|
| 節次目錄 | `GET /public/periods`(登入者由 `/auth/me` 帶,這裡沒有 session 才另外要一份) |
| 色格圖 | `GET /public/venues`、`/public/bookings/availability{,-range}`、`/public/equipment/usage` |

## 畫面

外殼是 `PublicShell`(與社團導覽共用):借用 shell 的 topbar 與內容寬,但**沒有側欄、通知鈴鐺與帳號選單** —— 匿名訪客沒有那些東西可以按。左上角系統名(點了回社團導覽),右上角固定兩顆:「借用狀態」與「登入」(**登入中時「登入」換成「控制台」**)。

內容區頂端一顆「回社團導覽」—— 左上角系統名在 767px 以下是 `display: none`,手機上沒有這顆鈕就回不去導覽頁。社團頁用的是同一顆(由 `PublicShell` 的 `back` 提供)。

內容是 `BookingGrid` 一張卡 —— 與社團端借用總覽、行政端臨時場地器材借用同一個元件,場地/器材切換、日期前後、單一場地 15 天下鑽全都在。

## 規則

- **點不動**:`BookingGrid` 沒收到借用入口就不畫可點的格子,可借格與未借滿的器材格都只是色塊
- 圖例不列「我的借用」(要有社團身分才判定得出來);格子也不帶待審單清單(那只給審核端)
- 這一頁與社團導覽都**不在角色閘底下**:登入中的人照樣看得到
- `/` **未登入**時是社團導覽:登入中的社團看總覽、其他角色轉自己的首頁。
  **開機檢查失敗(`/auth/me` 非 401)也照樣顯示導覽頁** —— 導覽頁不需要知道你是誰,
  而擋下來的代價是一個根本沒有帳號的校外訪客看到「無法確認登入狀態 / 改用其他帳號登入」,
  同一份內容在 `/clubs` 卻正常。代價是登入中的人在後端抖動時右上角會顯示「登入」
- 其餘社團端路徑沒有公開版本,未登入一律轉 `/login`;未知路徑轉 `/`
- 佔用格 hover 看得到借用單位名稱、不開放格 hover 看得到原因 —— **匿名一樣看得到**,
  判斷過這是校內張貼在場地門口的同一件事。不開放格是實心深灰,收掉原因等於讓匿名
  看到一格沒有任何說明的色塊。匿名唯一拿不到的是待審單清單
- 這一頁在正式環境仍受 edge 的台灣 IP 白名單保護(`../nginx` 那份副本),「免登入」不等於全世界打得到
