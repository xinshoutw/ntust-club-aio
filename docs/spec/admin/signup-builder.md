# 報名活動建立

`/admin/signup-items/new` · `admin` · 權限鍵 `asignup` · `features/admin/SignupBuilderPage.tsx`

## 用途

建立報名活動並自訂表單欄位。左邊編輯、右邊即時預覽社團端會看到的表單。

## 資料來源

`POST /admin/signup-items`

## 畫面

**活動資訊卡** — 活動名稱、活動類型(普通活動 / 幹訓 / 社團負責人會議)、地點、活動時間、名額上限、報名開始(預設今天)、報名截止、審核制勾選框、競賽報名勾選框、活動描述。

**資訊調查卡** — 自訂欄位清單。每列:拖曳把手、欄位名稱、型別(文字 / 多行文字 / 單選 / 複選 / 下拉)、必填勾選、刪除。選項型欄位下方是可編輯標籤(`TagListInput`,與系統設定共用):Tag 可刪,虛線「新增」點開行內輸入,Enter 或失焦即新增,逗號/頓號可一次多筆(所以選項文字本身不能含這兩個符號);重複的選項會被靜默略過。

排序支援指標拖曳(pointer 事件自製,掃過中線即換位)與**鍵盤方向鍵**(把手是可聚焦按鈕)。

**即時預覽欄** — 依目前設定渲染社團端表單:姓名 / 學號 / 系級三個固定欄位 + 自訂欄位 + 「+ 新增參加人(1/上限)」+ 送出鈕。

## 規則

- 活動類型決定行政分採計:`cadre_training` → ad8、`leader_meeting` → ad7 且自動設為場次制
- 送出時前端把三個基本欄位前置到自訂欄位前;自訂欄位不帶 key,由後端 `normalize_fields` 依序補 `f1`、`f2`…
- 驗證:名稱、活動時間、名額上限(≥1)、報名開始、報名截止皆必填;截止須晚於開始;活動時間與報名截止皆不得早於現在
- 未命名的自訂欄位不送出;選項型欄位至少要有一個選項
- 陣列順序即顯示順序
