# 違規勸導紀錄

`/violations` · `club` · `features/violations/ViolationsPage.tsx`

## 用途

社團查自己的違規勸導與銷案期限。唯讀,銷案要到學務處線下辦。

## 資料來源

`GET /club/violations?page&page_size`(每頁 20)

## 畫面

副標「請於 1 個月內至學務處活動辦理銷案,逾期將不受理」。

表格:日期、地點、違規項目(下方顯示補充說明)、銷案期限、狀態。銷案期限欄三種呈現:
- 已銷案或無期限 → `—`
- 已過期 → 紅字「YYYY/MM/DD 已截止」
- 期限內 → 日期 +「(剩 N 天)」或「(今日截止)」

## 規則

- **銷案期限 = 開立日 + 1 個月**,推導不儲存;期限當天仍可銷案
- 排序:未銷案在前,各組內依發生日升冪(與行政端一致)
- 未銷案且發生日落在評鑑視窗內的勸導,每筆扣行政分 1 分、上限 −10,**與是否逾期無關**
