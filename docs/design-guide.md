# club-aio 前端設計風格指南(Claude Design 設計簡報)

> 這份文件是設計提示詞:請 Claude Design 依此產出高擬真視覺設計(mockup)。
> 實作框架為 React + Ant Design 6,設計須可落地為 AntD 主題與元件組合,但**不要**長得像未調校的 AntD 預設模板。

## 1. 產品是什麼

臺灣科技大學學務處的**社團管理系統**:社團申請活動與經費、借用場地器材、繳交結案報告、參加社團評鑑;行政人員審核、公告、管理;評審評分;工讀生做器材點交與違規勸導。它取代紙本公文流程——每一張畫面背後都是一份「會被蓋章的表單」。

使用者與裝置:

| 角色 | 場景 | 裝置 |
|------|------|------|
| 社團幹部(20 歲上下學生) | 填申請、傳資料、查進度 | **手機為主**,桌機為輔 |
| 行政承辦 | 整天掛在審核與管理頁 | 桌機大螢幕 |
| 評審老師 | 集中一段時間評分 | 桌機/平板 |
| 工讀生 | 現場點交器材、拍照記違規 | **手機** |

## 2. 設計立場:公文的莊重,工具的輕快

方向宣言:**「數位公文」美學**——把台灣公文文化裡最有識別度的材料(明體字、朱紅印泥、關防章、編號)提煉成現代行政工具的視覺語言。整體安靜、精確、可信;唯一的華彩留給「簽核」這件事本身。

一句話測試:截圖任何一頁,應該讓人覺得「這是一套認真的校務系統」,而不是「又一個 admin dashboard 模板」。

**刻意的美學風險(僅此一處,其餘克制)**:頁面大標與關鍵儀式性時刻(登入頁、核准章)使用**明體(Noto Serif TC)**——公文的本體字體;搭配印章式的簽核視覺(見 §5)。其餘一律現代無襯線,避免全頁復古。

## 3. 設計代幣

### 3.1 色彩(named hex)

| 名稱 | Hex | 用途 |
|------|-----|------|
| 印泥紅 seal | `#9E1B32` | 主色:主要按鈕、選中態、進度、核准章。呼應臺科大校色與公文朱印;**克制使用**,每屏最多一個主紅焦點 |
| 墨 ink | `#1F2430` | 標題與正文 |
| 鋼灰 steel | `#5B6472` | 次要文字、標籤 |
| 界線 line | `#E4E7EC` | 分隔線、表格框 |
| 紙 paper | `#F5F6F8` | 版面底色(**冷灰白**,行政表格紙;禁用米黃/奶油色) |
| 卡面 surface | `#FFFFFF` | 卡片、表格底 |

語意色(獨立於主色,主紅≠錯誤紅,兩者刻意拉開):成功 `#2E7D57`、警示 `#B8730F`、錯誤/退回 `#D0453E`、資訊 `#2F6FBF`、學務長關卡紫 `#6B4FA3`。

### 3.2 狀態語意色票(本系統的核心視覺語言)

所有單據狀態用同一套 pill(淡底深字,AA 對比),全系統一致:

| 狀態 | 前景 | 底色 | 語意 |
|------|------|------|------|
| 草稿 | `#5B6472` | `#EEF0F3` | 未送出 |
| 待輔導老師審核 / 待審 | `#8A5A00` | `#FFF3D6` | 等待行政第一關 |
| 待組長審核 / 處理中 | `#1D5A9E` | `#E8F0FB` | 行政進行中 |
| 待學務長審核 | `#6B4FA3` | `#F0EBF9` | 最高關卡 |
| 已核准 | `#1F6B45` | `#E3F2E9` | 通過(描邊式) |
| 已結案 / 已完成 | 白 | `#2E7D57` | 終態(實心) |
| 已退回 | `#B03A2E` | `#FBE9E7` | 需修改重送 |
| 逾期 / 鎖定 | `#A3341F` | `#F9E4DE` | 帶鎖 icon,需管理員解鎖 |
| 停權 | `#3A3F4A` | `#E8EAEE` | 社團受限 |

### 3.3 字體(三役)

| 角色 | 字體 | 用法 |
|------|------|------|
| 展示 | **Noto Serif TC** 600/700 | 頁面大標(24–28px)、登入頁系統名、列印表單標題、核准章文字。僅此,不用於元件內 |
| 正文 | **Noto Sans TC** 400/500 | 一切 UI 文字,基準 14px;行政密表格可 13px |
| 資料 | **IBM Plex Mono** 或等寬 + `tabular-nums` | 單號、學號、金額、日期時間——所有會被人工核對的值 |

字級階:28 / 24(頁標,明體)、18(區塊標)、16(卡標)、14(正文)、13(表格/輔助)、12(標籤)。全部自架字體(CSP `self`),中文子集化。

### 3.4 形狀與空間

- 圓角 **6px** 統一(按鈕、卡、輸入框);pill 狀態標籤全圓角——是全系統唯一的全圓角元素,讓「狀態」一眼可辨
- 8pt 間距制;卡片內距 24px;區塊間 32px
- 陰影極輕(`0 1px 2px rgba(31,36,48,.06)`),層級主要靠界線與底色,不靠浮起
- 表格:斑馬紋**不用**,用 1px 界線 + hover 淡紅底 `#FBF3F4`

## 4. 版面系統

### 4.1 桌面外殼

```
┌────────────────────────────────────────────────────────┐
│ 臺科大社團管理系統          [114 學年 ▾]   [通知] [王小明 ▾] │  topbar 56px 白底
├──────────┬─────────────────────────────────────────────┤
│ 社團總覽   │  活動列表(明體 24)               [+ 活動申請]  │
│ 活動管理 ▾ │  ┌──────────────────────────────────────┐  │
│  · 活動申請│  │ 表格 / 卡片(白面、1px 界線、6px 角)     │  │
│  · 活動列表│  └──────────────────────────────────────┘  │
│ 社團管理 ▾ │                                            │
│ …         │                                            │
└──────────┴─────────────────────────────────────────────┘
 240px 白底側欄
```

- 側欄**白底**(拒絕深色側欄的預設 admin 感):選中項 = 左緣 3px 印泥紅條 + `#FBF3F4` 淡紅底 + 墨字轉紅字;群組標籤 12px 鋼灰
- topbar 常駐「學年度」切換——本系統一切資料掛學年
- 圖示一律 `@ant-design/icons`(SVG);**全系統禁止 emoji**

### 4.2 響應式

斷點依 AntD(576/768/992/1200)。<768px:側欄收為 Drawer;表格轉**卡片列**(每列一卡:標題+狀態 pill+兩三個關鍵欄+動作);表單全寬單欄。手機優先頁:社團端全部、工讀生點交/違規(大按鈕、大觸擊區、拍照上傳直達)。

### 4.3 內容寬度

表單類單欄 max-width 720px(填表是線性任務);表格/總覽全寬;詳情頁 = 左內容 + 右側 320px 資訊欄(簽核軌、時間線)。

## 5. 簽名元素:簽核章軌(StampTrail)

每張單據詳情的固定視覺——把「輔導老師 → 組長 → 學務長」流程畫成**關防章軌**:

```
  ●━━━━━━━━◐┈┈┈┈┈┈┈○          ● 已核:實心印泥紅圓章,章內單字(輔/組/長),下方核准日+姓名
 [輔]     [組]     [長]        ◐ 當前:琥珀實線描邊,微弱脈動
                               ○ 未到:灰虛線描邊
  退回:緋紅章 + 斜杠,點開看原因
```

- 章 32px 圓,章內字用明體;連線 2px(完成段實線墨色,未完成虛線)
- 無經費活動只有單章;結案流程同組件複用;列印時同樣呈現(黑白可辨)
- 這是系統的記憶點:狀態不只是一個 pill,而是「章蓋到哪了」

## 6. 元件模式

- **表格**:行動作放行尾(文字鈕,主動作紅字);批次選取才出現底部動作條;每表都有欄位排序與篩選,但篩選收進表頭,不做一排篩選器牆
- **表單**:區塊化(基本資料/經費明細/附件),區塊標 16px;經費明細用可增刪動態列,底部即時合計(mono 字);必填星號,行內驗證,送出前總覽確認
- **動態報名表單**(管理員自訂欄位):子頁渲染 fields schema;多人報名 = 「參加人」卡片堆疊,每卡一組欄位,底部「+ 新增參加人(3/5)」,達上限變禁用並顯示配額
- **上傳**:拖放區 + 檔案列(檔名、大小、上傳者、時間);已歸檔檔案顯示「已歸檔」灰態而非壞連結
- **空狀態**:一句話 + 主動作按鈕(「尚無活動申請。」[提出活動申請]);不放插圖不放 emoji
- **載入**:Skeleton(表格骨架列),不用整頁 spinner
- **錯誤**:說發生什麼+怎麼辦;表單錯誤捲到第一個錯欄
- **確認**:危險動作(退回、刪除、停權)用對話框且要填原因——原因必填是本系統規則

## 7. 文案聲音

繁體中文;按鈕動詞開頭且前後一致(「送出申請」→ toast「已送出」);狀態是名詞;不用驚嘆號、不用表情、不道歉;說明文字能省則省——欄位說明優先放 placeholder 或 Tooltip,**版面上不堆說明段落**(需求方明定)。

## 8. 動效與無障礙

- 動效只在:頁面切換淡入(150ms)、章軌當前節點脈動、pill 狀態變更一次淡色閃現;`prefers-reduced-motion` 全關
- 對比 WCAG AA;focus ring 2px `#2F6FBF`;表格可鍵盤導航;所有 icon 按鈕帶 aria-label

## 9. 請產出的關鍵畫面(依優先序)

1. **登入頁**:紙色底、置中單卡;系統名用明體、一枚小印泥紅印章元素;帳密 + 登入;**不要**漸層、插圖、blob
2. **社團總覽**(社團端首頁):公告卡 + 「進行中申請」狀態一覽(各類申請的 pill 摘要,取代舊「我的申請進度」頁)+ 待辦(逾期結案警示)
3. **活動列表**:表格含狀態 pill、每列動作「編輯/送出/**結案**」視狀態而定;「已退回」列展開可見退回原因;含手機卡片式版本
4. **活動申請表單**:720px 單欄、經費動態列與合計、附件區、頂部章軌預覽(顯示送出後會走的關卡)
5. **線上報名**:活動卡片列表(名稱、截止、名額 12/30、狀態)→ 子頁:自訂欄位表單 + 多人參加卡片堆疊
6. **行政:活動申請審核**(桌面):密表格 + 右側詳情抽屜(章軌、逐項核定金額輸入、核准/退回按鈕,退回強制填原因)

每張畫面同時交付:桌面 1440px;畫面 2、3、5 另交手機 375px 版本。

## 10. 禁止事項

- emoji(一律 AntD SVG icon 或符號)
- 米黃/奶油底 + 襯線標題 + 陶土色的「AI 預設文青風」;近黑底 + 螢光單色的「AI 預設暗黑風」;整頁 hairline 報紙風
- 深色側欄、漸層英雄區、裝飾性插圖、資訊卡上的大數字儀表板拼貼
- 版面上的長段說明文字(收進 Tooltip)
- 深色模式(暫不設計,先做好唯一的亮色)
