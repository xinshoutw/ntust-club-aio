# 郵局帳戶異動

`/postal` · `club` · `features/applications/PostalPage.tsx`

## 用途

社團郵局帳戶的六種異動申請。副標寫「公文作業約 3–5 個工作天」。

## 資料來源

| 動作 | 端點 |
|---|---|
| 列表 | `GET /club/postal-changes?status=`(正在申請=未完成全部;最近申請=已完成 `page_size=5`) |
| 送出 | `POST /club/postal-changes` |
| 上傳存簿 | `POST /club/postal-changes/{id}/passbook` |

## 畫面

表單:事由複選(更換郵局存簿代理人 / 新開戶 / 帳戶印鑑章變更 / 帳簿遺失 / 存簿密碼異動 / 結清銷戶)、存簿戶名、存簿局號帳號、新代理人姓名與電話(勾到需要的事由才出現)、原存簿影本或新開戶申請表(單檔,PDF 或圖片)。

下方兩張表:正在申請(非 `completed`)、最近申請(`completed` 近 5 筆),顯示事由、戶名與帳號、申請日期、狀態。

## 規則

- **事由不設互斥組合**,完全依社團勾選記錄(decisions.md D-07)—— 一次辦好幾件本來就常見。事由本身必填(至少一項)且不得重複
- **事由以外全部選填**:結清銷戶不必填新代理人,新開戶當下也還沒有帳號可填。強制必填只會逼社團填假資料
- 勾了「新開戶」時,附件欄下方出現「社團於本校郵局新開戶申請表」空白表的下載連結(站內留存於 `frontend/public/postal-new-account-form.pdf`,**檔案異動走 infra,前端不提供替換**)
- 局號帳號格式 6–20 碼數字(可含 `-`)
- 存簿影本固定 50MB 上限,**後台調不到**;一張申請只收一份(前端 `maxCount=1`,後端亦擋)
- **社團看自己的申請顯示完整局號帳號**(不遮罩);行政端與其他情境走 `mask_account`(前 3 + 末 2)。電話一律遮罩成末 3 碼
- 狀態:`pending`(審核中)→ `processing`(處理中)→ `completed`(請洽學務處),**無退回**

## 未完成 / 問題

- 存簿影本是必填(前端擋),後端 `POST` 允許零附件。兩段式流程:上傳失敗時申請已建立,列表沒有補傳入口,只能再送一張新單
