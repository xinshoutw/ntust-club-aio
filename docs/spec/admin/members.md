# 成員列表(行政端)

`/admin/members` · `admin` · 權限鍵 `amember` · `features/admin/AdminMembersPage.tsx`

## 用途

查閱單一社團的成員名冊並匯出 CSV。**唯讀** —— 名單由社團自行維護。

## 資料來源

`GET /admin/clubs/{club_id}/members?semester&sort&page&page_size`(每頁筆數依視窗高,見 `lib/fitRows`;參數與排序白名單和社團端 `/club/members` 共用同一份實作)

學期下拉:`GET /admin/clubs/{club_id}/members/semesters`(該社名單實際有資料的學期,新到舊)

## 畫面

頁首:學期下拉、匯出 CSV、選擇社團。表格:姓名、學號、身份、職稱、學期、入社時間、更新時間,皆可多鍵排序(伺服器端);時間欄寬 156px 讓 `YYYY/MM/DD HH:mm` 不截斷;每一欄都給 px、沒有 auto 欄,寬螢幕的餘裕按比例攤回每一欄、窄時由外層橫捲(版面同社團端,欄寬另計:這頁密一級且沒有動作欄)。卡片撐到視窗底、每頁筆數依高度算,分頁列貼著卡片底邊。

## 規則

- 身份顯示詞依所選社團的 `kind` 推導(社團→社長、學會→會長)
- **所有欄位不換行**;寬度不足時依序隱藏兩個時間欄(先收更新時間、再收入社時間,`lib/memberTable.useMemberTimeColumns`)。正在依某個時間欄排序時該欄一律留著 —— 收掉的話使用者看不到也取消不了自己下的排序
- **負責人與副負責人的職稱一律顯示 `—`**(D-27,`lib/roles.memberTitle`):規則生效前存下的殘留值不在畫面與匯出露出來,否則同一列社團端顯示 `—`、這裡顯示原文
- 匯出格式與社團端匯入相容(無標題列、身份用顯示詞),**不含兩個時間欄**
- 切換社團或學期都會重設回第 1 頁;換社團同時把學期回到當前學期(上一社選的學期在新社可能不存在)
- 學期下拉 = 該社名單實際有的學期 + **一定補上的當前學期**(`lib/semester.semesterOptions`,新社還沒有名單也選得到);因此選項查詢失敗時畫面看起來正常、只少了全部歷史學期 —— 那時下拉旁邊要顯示「學期清單載入失敗 + 重試」(`components/ui/OptionsError`)
