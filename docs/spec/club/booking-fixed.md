# 固定場地借用

`/bookings/fixed` · `club` · `features/bookings/FixedRoomPage.tsx`

## 用途

申請**整學期每週固定時段**的場地。選的是「星期 × 時段」,不是日期。

## 資料來源

| 動作 | 端點 |
|---|---|
| 開放窗 | `GET /club/room-bookings/window` |
| 場地主檔 | `GET /club/venues`(取 `allow_fixed`) |
| 場況(每週佔用) | `GET /club/room-bookings/occupancy?venue_id=`(選了場地才查) |
| 正在申請 / 最近申請 | `GET /club/room-bookings?active=true\|false` |
| 送出 | `POST /club/room-bookings` |
| 取消 | `POST /club/room-bookings/{id}/cancel` |

## 畫面

**開放窗外整頁只顯示**「目前未開放申請」+ 受理期間,表單不渲染。查詢失敗時顯示錯誤與重試,不會誤判成未開放 —— 側欄同理:開放窗查詢失敗時項目**保持可點**(反灰會讓這頁的錯誤與重試永遠到不了),見 `lib/nav.tsx` 與 `lib/nav.test.ts`。

開放時:場地下拉 + 用途 + 7×14 的每週時段選格(已被佔用的格子停用並標示原因,下方附圖例)(滑鼠/觸控筆可按住拖曳批量選取/取消,`useDragSelect` 與 `PeriodPicker` 共用)+「本學期已申請 N 節・已選 M / 可用 K 節」計數(額度為跨申請單合計,由後端提供),底部送出鈕。下方兩張表:正在申請(可取消)、最近申請(近 5 筆)。退回原因隨清單端點回傳(借用總覽的「最近申請」可點開)。

## 規則

- 目標學期由**受理期間結束日**推導的下一學期(`booking_service.fixed_target_semester`),起訖日快照寫進申請單。不看「今天」是因為開放窗會跨學期邊界(例 7/25–8/5),照今天推導的話同一輪申請會落到兩個學期、10 節額度在期間中途重置一次;一律取較後面的那個學期(decisions.md ISS-33)。推出來的學期**已經結束**時才退回以今天推導 —— 夾成 `max(open_until, today)` 的話,目標學期一開學就會往前跳一格,社團的已用節數在學期中途歸零
- 每社至多 **10 節**;額度以「同一目標學期、狀態非 rejected/cancelled」合計 —— 審核中也佔額度;檢核前先取該社團的 advisory lock(`club`),並發送出不會各自通過同一份合計
- 開放窗端點一併回本社已佔用節數與上限(`used_periods`/`max_periods`),與送出檢核同一份查詢:表單上方顯示「本學期已申請 N 節・已選 M / 可用 K 節」
- **場況由後端判定**:`/occupancy` 回下一學期該場地每週 (星期×節次) 的佔用與原因 —— `blocked`(場地不開放規則)、`fixed`(別社已核准的固定借用)、`temp`(學期內已核准的單日臨時借用),三條與**核准**關的檢核同一份判定(送出關只擋不開放規則:多社競爭同一時段本來就允許,由承辦整單擇一)。前端不自行推導(臨時借用要逐日展開、不開放規則帶自己的日期區間,前端都算不對)
- 場況未就緒時整張表換成 Skeleton,查詢失敗則整表與送出鈕一併停用並顯示錯誤與重試 —— 空的佔用表看起來就是「整週都可借」
- 換場地時把已選但在新場地被佔用的格子拿掉並提示移除了幾格;佔用格停用,拖曳掃過去也不會選到
- **晚間時段規則**:含第 10 節或 A–D 節的連續區段至少 3 節。合法 `9–A`、`8–10`、`A–C`、`B–D`;不合法 `9–10`、`C–D`。前後端各實作一份(`runsOf` / `runs_of`)
- 多社可申請同一時段,衝突由管理員**整單擇一核准**,不存在部分同意
- 停權中的社團送出時被擋(403 `CLUB_SUSPENDED`);頁首同時顯示停權標示與到期日,送出鈕停用。社團資料查詢首載失敗時頁首改顯示「無法確認停權狀態」(不可靜靜當成未停權)
- 送出時檢核場地不開放規則:學期區間內只要有**一天**的該星期該節次被封,整個時段就不受理(422);核准那關再檢核一次(送出後才新增的規則吃 409 `SLOT_BLOCKED`)
- 拖曳選格走 pointer 事件,滑鼠與觸控筆按下即選、掃過即套用;**觸控只認單點**(按下當下不套用)—— 兩張時段表在手機上都要橫向捲,手指按在格子上開始捲是常態,捲動不會產生 click
