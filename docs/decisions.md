# 決策紀錄

需求方(學務處)與系統管理端拍板的規則。**這裡記「為什麼系統是這樣」,不記進度**;
進度看 [`HANDOFF.md`](HANDOFF.md),行為細節看 [`spec/`](spec/)。

一條決策落地後,對應的 `ISS-` / `GAP-` / `DEC-` 編號就從 `issues.md` / `gaps.md` 移除,
但本檔的條目**永久保留** —— 後人問「為什麼不能改成 X」時,答案在這裡。

## 2026-08-18 第一批(決策單第一至三節)

### 權限與帳號

| 編號 | 決策 |
|---|---|
| **D-01** | **每一個側欄頁面各自一個權限鍵**,包含目前 super 專屬的五頁(器材主檔與手動借用、場地不開放規則、逾期追蹤與停權管理、系統設定、稽核軌跡)。管理員可逐頁勾選授權,不再有「只有 super 看得到」的頁面 |
| **D-02** | 檔案下載權限**跟著 D-01 的頁面權限走**,不另立分類。看得到那一頁 = 下載得了那一頁的檔案 |
| **D-11** | 刪掉「線上申請管理」頁,在「其他」類別下獨立成**「證明管理」與「郵局管理」兩頁**,各自一個權限鍵 |
| **ISS-25** | 重設社團密碼歸**「管理項目」**權限,不歸 super |

### 活動與經費

| 編號 | 決策 |
|---|---|
| **D-03** | 承辦核定金額**不得高於社團擬請補助**,前後端都擋 |
| **ISS-54** | 大型活動認可**可於後續關卡修改**,不再固化於第一關 |
| **DEC-08** | 行政分總分**下限為 0**,不可為負 |

### 退回與時效

| 編號 | 決策 |
|---|---|
| **D-05 / ISS-29** | 活動日期已過的**退回件可照原日期重送**,不強迫改成未來日期 |
| **D-05 / ISS-30** | 結案退回件**不受鎖定期限限制**,可自行重送,不必請行政解鎖 |
| **D-04 / DEC-03** | 固定場地借用**申請期間結束後,承辦仍可續審**已收到的單;社團不能再送新的 |
| **ISS-33** | 開放窗跨學期時,**一律以較後面的學期為目標學期**,且只對該學期生效 |

### 借用與器材

| 編號 | 決策 |
|---|---|

### 線上申請

| 編號 | 決策 |
|---|---|
| **D-06 / ISS-09** | 空間報修與郵局異動的**附件必附**,並在列表加逐單補傳入口 |
| **D-07 / ISS-10** | 郵局帳戶異動**取消三組互斥限制**,完全依使用者勾選記錄;**除勾選項外所有欄位改選填**。「新開戶申請表」加超連結指向站內留存的 PDF(檔案異動走 infra,前端不提供替換) |

### 維運與遷移

| 編號 | 決策 |
|---|---|
| **OPS-01** | **僅自動備份 DB 並存放於同一環境**(防誤刪與系統錯誤),不做異地備份。需要時 infra 主動連上處理 |

| **MIG-05** | 社團聯絡 Email 由腳本自動生成:取**最新學期「負責人」身份的學生學號** + `@mail.ntust.edu.tw`。無負責人者列為例外輸出。Discord webhook 預設留空 |
| **GAP-08** | 檔案歸檔**純由 infra 處理**,系統不做歸檔介面 |
