# 固定場地借用審核

`/admin/rooms` · `admin` · 權限鍵 `aroom` · `features/admin/AdminRoomsPage.tsx`

## 用途

固定場地借用申請的單關審核。衝突時整單擇一核准,不做部分同意。

## 資料來源

| 動作 | 端點 |
|---|---|
| 開放窗 | `GET /admin/room-bookings/window`(一般 admin 即可讀,供側欄反灰) |
| 待審清單 | `GET /admin/room-bookings?status=pending`(每頁 50) |
| 核准 / 退回 | `POST /admin/room-bookings/{id}/{approve,reject}` |

## 畫面

**開放窗外整頁只顯示**「目前未開放申請」+ 受理期間 + 「可於系統設定調整開放區間」。

開放時:待審表格(社團、場地、每週時段、用途、狀態)。互相衝突的時段以紅字加「(衝突)」標示 —— 衝突判定是前端在**本頁已載入的待審單**之間比對「同場地 × 同星期 × 同時段」。

**審核彈窗** — 場地名、社團、用途、每週時段逐列(衝突紅字);有衝突時顯示「此申請與其他申請衝突,請擇一核准」。動作:退回(原因**預填一段固定文案**,可改)、核准。

## 規則

- 核准時以 advisory lock 鎖場地,檢查同場地、學期區間重疊、狀態為已核准的單是否已佔用相同 `(weekday, period)`(`SLOT_TAKEN`)
- 一單多時段,核准即全部生效;退回原因必填

## 未完成 / 問題

- **開放窗一結束,承辦人就審不了已收到的申請** —— 整頁被鎖,待審單無處可審。這行為是否維持尚未經承辦確認
- 衝突標示只比對「當前這一頁」的待審單:超過 50 筆或分頁後,跨頁的衝突看不出來
- 核准不檢核場地不開放規則(已核准的臨時借用則會交叉檢核)
- 固定場地衝突查詢缺少可用索引
