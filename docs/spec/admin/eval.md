# 評鑑行政分審核

`/admin/eval` · `admin` · 權限鍵 `aeval` · `features/admin/AdminEvalPage.tsx`

## 用途

逐項調整社團的行政分(ad1–ad8 + 加減分),或登錄表現優良加分。調整即時反映到社團端。

## 資料來源

| 動作 | 端點 |
|---|---|
| 各社行政分總覽 | `GET /admin/eval/clubs` |
| 單社明細與調整紀錄 | `GET /admin/eval/clubs/{id}` |
| 手動調整 / 回到自動 / 加分 | `POST /admin/eval/clubs/{id}/{override,revert,merit}` |

## 畫面

頁首:年度、選擇社團、右側「採用總分 N / 100」。

**行政分表** — 每列:評分項目(名稱 + 分組 + 計算說明)、自動計算(auto / 滿分)、採用分數(final,被調整過加「已調整」標記與 Tooltip 顯示自動值與原因)、動作(手動調整分數 / 回到自動計算結果)。最後一列固定是「表現優良加分」,動作為「登錄加分」。

**各社團行政分** — 社團、性質、行政分總分。點列切換上方審核對象。

**調整彈窗** 三種模式:手動調整分數(輸入分數 + 原因)、回到自動計算結果(只填原因)、表現優良加分(0–5 + 原因)。**原因一律必填**。

## 規則

- 調整全部留痕於 `eval_adjustments`;「回到自動」= 把該項現行調整列填 `revoked_at` 註銷,不硬刪
- 新調整會先註銷同 key 的舊調整,再新增一列;調整/回到自動/加分三支端點都先取該社團的 advisory lock,並發不會互相蓋掉
- 表現優良加分同理:最新一筆生效,舊列註銷
- 分數範圍:一般項 0–該項滿分;加減分項 −10 至 +5;表現優良 0–5
- 每次調整都寫 `audit_logs` 並推 Discord 通知該社
- 各社總覽是一次批次彙整(每個資料來源各查一次,往返次數與社團數無關),**只回總分**;逐項明細由 `/clubs/{id}` 供應

## 未完成 / 問題

- **逐年 rubric 與獎項主檔沒有管理介面**:新學年的評分項目只能改 seed 或直接動 DB
- 沒有「競賽資料完成度」總表,承辦看不出哪些社團還沒交資料
- 沒有分組與評審指派介面(見 [../viewer/my-reviews.md](../viewer/my-reviews.md))
- 沒有競賽成績總表:跨評審平均、40%/60% 加權、名次全部無處產生
