## P1 — 應優先修(真缺陷)

### 1. 器材主檔「總數」欄每個按鍵送一次 PATCH〔前端 HIGH〕
`frontend/src/features/admin/AdminEquipmentCard.tsx:47-54`(InputNumber `onChange` 直接 PATCH)。同列「名稱」欄用 `onBlur`(line 36)才對。把 25 改成 80(鍵入 8、0)→ 送 PATCH(8) 與 PATCH(80) 兩次;若回應順序顛倒,主檔停在中間值 `8`。此欄驅動可借數推導,寫中間值是資料正確性風險。
**修法**:總數欄改 `onBlur` 提交(比照名稱欄);或本地 state + blur。同檔 LOW 6(名稱本地 state 不隨 refetch 同步、併發改名互蓋)可一併以「本地 draft + blur diff」處理。

### 2. 結案送出 vs 刪照片跨端點競態 + `/close` 未驗證照片〔codex HIGH〕
`backend/app/api/v1/activities.py`(`submit_close` 約 426、`delete_photo` 約 288)。兩者都 `get_own_activity` 後直接改/刪、無列鎖。極窄競態:client 於 `/close` 處理中逾時 → 前端 catch 觸發回滾刪照片(`ActivityClosePage.tsx:397` 起),`delete_photo` 於 `/close` commit 前讀到 `approved` → 刪光照片 → `/close` 仍 commit,形成「已送審但零照片」的結案。且 `/close` 後端**完全未驗證至少一張照片**(僅前端擋),直呼 API 可零照片結案。
**修法**:`submit_close` 與 `delete_photo` 對 activity 列 `with_for_update`(統一鎖序);`submit_close` 取鎖後重查 `report_photo` slot 未歸檔張數,`== 0` 回 422。`delete_photo` 已檢 `status==APPROVED`,加列鎖後即與 `/close` 序列化(close 先 commit → 後續刪除見 closing → 409)。

### 3. 送出失敗 + 重載後孤兒照片無回收路徑〔codex HIGH / 前端 MEDIUM〕
`frontend/src/features/activities/ActivityClosePage.tsx`(photo id 僅存記憶體、`submit` 約 397、後端 `/photos` dedup=slot 跨活動 sha256)。若 `/photos` 已 commit 但回應遺失/關分頁,id 無法回滾;重開結案頁**忽略後端已回的 `detail.photos`**,重選同張 → 409 去重擋、舊檔續佔 10MB 額度,使用者卡死無法結案;或回滾 `deleteActivityPhoto` 也失敗(`Promise.allSettled` 吞掉)同樣卡死。
**修法**:結案表單載入時把 `detail.photos`(APPROVED 狀態下只會是前次失敗殘留的孤兒)顯示為**可移除的既有照片**(比照活動申請頁 existing + bag 模式),加總/MIN_PHOTOS 併計 existing + 新增。使用者即可看見並刪除孤兒,回收 10MB 並重送。

### 4. 固定借用場況「永久佔格」— 資料模型缺學期界限〔後端 HIGH〕
`backend/app/services/booking_service.py:202-238`(`fixed_rows` 僅 `status != REJECTED`)。`RoomBookingRequest`(`app/models/bookings.py:11`)**無日期/學期欄位**,只有 slot 的 weekday。故任何未退回固定借用會在其 weekday 於**所有被查詢日期永久顯示**(含跨學期);本次新納入 pending 使「審核中」也永久污染。與需求「固定借用=整學期每週固定時段、僅開放窗受理」矛盾。
**修法(需資料模型決策)**:`RoomBookingRequest` 加學期/生效區間欄(或綁 `fixed_booking_window` 的學期),grid 查詢依當前學期/區間過濾。屬較大改動,需與需求方確認固定借用的學期歸屬語義。附帶:LOW「場況查詢無 venue 篩選、Python 端 O(天數×全校 slot) 比對」會隨此缺口單調成長,一併加 venue 條件與 weekday SQL 過濾。

### 6. `budget_categories` 舊字串格式 → 500〔後端 LOW〕
