# 成員列表

`/members` · `club` · `features/members/MembersPage.tsx`

> 這頁是 `src/api/{domain}.ts` 的接線範本(`api/members.ts` + 本頁),新頁面照這個寫。

## 用途

維護該社**逐學期**的成員名冊。名單是 ad5 行政分的依據。

## 資料來源

| 動作 | 端點 |
|---|---|
| 學期選項 | `GET /club/members/semesters` |
| 列表 | `GET /club/members?semester&kind&sort&page&page_size` |
| 新增 / 修改 / 移除 | `POST`、`PATCH /{id}`、`DELETE /{id}` |
| CSV 匯入 | `POST /club/members/import` |

## 畫面

頁首:人數 + 學期下拉(含「全部學期」)+ 匯入 CSV + 匯出 CSV + 新增社員。學期選項 = 名單實際有的學期 + **一定補上的當前學期**,因此查詢失敗時選單看起來正常、只少了全部歷史學期 —— 那時下拉旁邊顯示「學期清單載入失敗 + 重試」(`components/ui/OptionsError`)。

表格欄位:姓名、學號、身份、職稱、學期、入社時間、更新時間、動作(移除);**學期與兩個時間欄靠右對齊**(等寬數字對成一直行),時間欄寬 156px 讓 `YYYY/MM/DD HH:mm` 不截斷。身份與職稱**可行內編輯**(點擊變輸入框,選完或 blur 即送出)。身份欄可多選篩選;姓名/學號/身份/職稱/學期/入社時間/更新時間可多鍵排序。

三個對話框:新增社員(姓名、學號、學期、身份、職稱)、匯入 CSV(選學期 + 選檔或貼上)、匯出 CSV(選學期)。

## 規則

- 身份標準值固定四種:社員 / 幹部 / 副負責人 / 負責人;顯示詞依社團 `kind` 推導(社團→社長、學會→會長)
- **職稱只有「幹部」必填**,其他身份選填
- 唯一鍵是 `(club_id, student_id, semester)`;同學號可跨學期重複出現
- CSV 格式 `姓名,學號,身份[,職稱]`,無標題列;**不收電話**(D-21,舊資料的號碼隨欄位一併拋棄);匯入接受顯示詞並映射回標準值;剝除 UTF-8 BOM 與匯出端補的公式中和單引號;同學期同學號 upsert
- **入社時間 = `created_at`**,行內編輯只會動 `updated_at`。遷移把舊系統的入社日期寫進 `created_at` 與 `updated_at`,兩欄並存才讓那份日期在改過資料之後仍看得到
- 入社時間是**這一列(這一學期)建立的時間**,不是「第一次入社」:名單一學期一列,連續在社的老社員在下學期名單匯進來時會拿到匯入當天的入社時間。與舊系統 `Club_student.Date` 同語意
- **所有欄位不換行**;寬度不足時依序隱藏兩個時間欄(先收更新時間、再收入社時間,`lib/memberTable.useMemberTimeColumns`)。正在依某個時間欄排序時該欄一律留著
- **值沒變就不寫入**:no-op 重匯與行內編輯未改值都不會動 `updated_at`,讓列表的「更新時間」可信。**與 ad5 計分無關** —— ad5 是逐學期數人頭(0 人 0 分、1–9 人 2.5 分、≥10 人 5 分),完全不讀 `updated_at`
- 匯出走前端逐頁抓齊後產 CSV,格式與匯入相容
- 排序與分頁**都在後端**(白名單 `_SORTABLE`,固定補 `id` tiebreak),與其他清單頁不同
