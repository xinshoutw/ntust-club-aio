# 社團總覽(行政端)

`/admin/club-overview` · `admin` · 權限鍵 `amember` · `features/admin/ClubOverviewPage.tsx`

## 用途

以單一社團為視角看它的進行中申請與借用中項目,並就地審核。是社團端總覽的行政版。

行政端三頁(本頁、成員列表、管理項目)共用同一個「選擇社團」狀態(`AdminClubProvider`),跨頁同步。

## 資料來源

| 區塊 | 端點 | 需要權限 |
|---|---|---|
| 基本資料 | `GET /admin/clubs/{id}` | `amember` |
| 進行中活動 | `GET /admin/activities?club_id=` | `areview`/`aclose` |
| 空間報修 | `GET /admin/maintenance?club_id=` | `amaint` |
| 固定借用 | `GET /admin/room-bookings?club_id=` | `aroom` |
| 臨時借用 / 器材 | `GET /admin/{venue-bookings,equipment-loans}?club_id=` | `abooking` |

## 畫面

**基本資料卡** — 性質、帳號(停用時標紅)、網頁連結、簡介、聯絡 Email。

**進行中申請**(左)— 活動申請與空間報修混列,點活動開審核彈窗(與申請審核頁同版面,待審者可直接核准/退回),點報修開唯讀詳情。

**借用中**(右)— 固定場地 / 臨時場地 / 器材混列,點列開借用審核彈窗(與臨時場地器材審核頁同版面)。

## 規則

- **受限管理員不發沒權限的查詢**,該區塊改顯示「您的權限無法檢視此區塊」而不是整排 403 錯誤
- 已退回 / 已歸還的項目不列入
- 固定借用的衝突標示與 `/admin/rooms` 同邏輯,但同樣只比對**前 50 筆待審單**

**撤銷已核准的借用**:本頁是唯一同時看得到三類已核准借用的地方,借用彈窗對 `approved` 顯示「撤銷借用」(原因必填,狀態落 `cancelled`;固定借用的 10 節額度隨之回歸)。臨時場地日期已過、器材已借出者不得撤銷 —— 器材要走歸還。

- 未選社團時整頁是空的,沒有引導文字
