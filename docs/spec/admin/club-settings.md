# 管理項目(行政端)

`/admin/club-settings` · `admin` · 權限鍵 `amember` · `features/admin/AdminClubSettingsPage.tsx`

## 用途

社團主檔與帳號管理:改名稱、改類型、改帳號、啟停用、重設密碼。社團自己維護的內容在此**唯讀**。

## 資料來源

| 動作 | 端點 |
|---|---|
| 詳情 | `GET /admin/clubs/{id}` |
| 更新 | `PATCH /admin/clubs/{id}` |
| 重設密碼 | `POST /admin/clubs/{id}/reset-password` |
| 建立帳號 | `POST /admin/clubs/{id}/account`(入口在帳號管理) |

## 畫面

左右兩張卡。

**社團資料**(唯讀)— 英文名稱、校內指導老師、校外指導老師、網頁連結、簡介、聯絡 Email、Discord Webhook(只顯示「已設定/未設定」,**不回傳實值**)。詳情載入失敗且手上沒有資料時,兩張卡都改顯示失敗原因與重試 —— 整排 `—` 看起來像「這社什麼都沒填」;背景重抓失敗則資料照舊、底下補一行說明。

**帳號與狀態**(可編輯)— 社團名稱、類型(社團/學會)、社團帳號、帳號狀態開關、停權中提示;底部「重設密碼」與「儲存」。

修改過的欄位加橘黃外框。切換社團時若有未儲存變更會先確認,取消則留在原社團。

## 規則

- 名稱結尾是「社」或「會」時**自動推導類型且類型下拉停用**;其他結尾才手動指定。前後端各一份 `deriveKind` / `derive_kind`
- 只送有變更的欄位;顯式 `null` 視同未提供(名稱、類型、帳號皆不可清空)
- 停用社團時**主檔與帳號同步停用並立即撤銷所有 session**;儲存前跳確認
- 重設密碼:產生一次性密碼、寫 `password_history`、`must_change_password=true`、清除鎖定計數、撤銷所有 session。明碼只在該次回應出現,以彈窗一次性顯示
- 所有變更寫 `audit_logs`
