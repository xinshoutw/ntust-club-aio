# 借用總覽

`/bookings` · `club` · `features/bookings/BookingOverviewPage.tsx`

## 用途

看場況、看自己所有進行中的借用(三類合一)、取消借用、從空格直接跳去申請,以及查最近結案的申請與退回原因。

## 資料來源

| 區塊 | 端點 |
|---|---|
| 場地主檔 | `GET /club/venues` |
| 單日場況 | `GET /club/bookings/availability?date=` |
| 單一場地多日場況 | `GET /club/bookings/availability-range?start&end&venue`(上限 31 天) |
| 正在借用(三類) | `GET /club/{room-bookings,venue-bookings,equipment-loans}?active=true` |
| 最近歸還 | `GET /club/equipment-loans?status=returned`(伺服器分頁) |
| 最近申請(三類) | `GET /club/{room-bookings,venue-bookings,equipment-loans}?active=false`(各取第一頁 5 筆) |
| 取消 | `POST /club/{…}/{id}/cancel` |

## 畫面

**場地借用情形**(色格圖)— 兩種檢視:

1. 單日全場地:列 = 場地、欄 = 14 節次。日期切換鈕(前後一天/一週/今天)+ 日期選擇器。
2. 單一場地 15 天:點場地名稱進入,以當時檢視日為中心 −7~+7。

兩種檢視都可往前看過去日期(查歷史借用紀錄的唯一入口)。

格子狀態:可借(淺灰)/ 審核中(橘)/ 臨時借用(粉)/ 固定借用(深灰)/ 我的借用(綠)/ 僅固定借用(斜紋)/ 不開放(透明無框)。這張圖是**臨時借用**的視角,只開放固定借用的場地標「僅固定借用」而不是「不開放」。可借格可點,直接帶場地+日期+節次跳到臨時場地借用頁。被佔用格 hover 顯示借用社團名。

**正在借用** — 固定場地 / 臨時場地 / 器材三類混在同一張表(類別、內容、時間、狀態、動作),不分頁、全部列出。

**最近歸還** — 已歸還的器材借用,伺服器端分頁,每頁 10 筆。

**最近申請** — 已結束/退回/取消的近況,三類混在同一張表(類別、內容、時間、狀態),各取第一頁 5 筆(要翻更早的到各借用頁)。已歸還的器材不重複列(上一張卡就是它們)。退回件整列可點,開出退回原因與退回時間。

## 規則

- 停權中的社團在頁首看到停權標示與到期日(原因收在 Tooltip),不必送出撞 403 才知道;社團資料查詢首載失敗時改顯示「無法確認停權狀態」
- 場況圖的格子權重:`blocked` > `mine` > `temp`/`fixed` > `pending`;審核中(含本社自己的)一律顯示「審核中」;同一格多筆時取先送件者的社名 hover(臨時借用優先於固定借用,各類內依申請 id)
- 過去日期只供查閱:那些天的可借格不可點(申請本來就禁過去時間)
- 固定借用只在其目標學期起訖區間內佔格,學期結束即釋出
- 退回原因來自 `approval_records` 最後一筆 REJECT,由三支清單端點一併回傳;可不可點看**狀態**不看有無原因 —— 舊系統遷入的退回件多半沒留理由,彈窗直說「系統未留下退回原因」,不做成點不動的列
- 取消條件三類不同:
  - 固定場地、器材 — 審核中隨時可取消;已核准僅開始日**之前**可取消
  - 臨時場地 — 審核中與已核准一致,以**最早節次的起始時刻**為界
