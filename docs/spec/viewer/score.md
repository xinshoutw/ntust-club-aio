# 評分(依獎項)

`/viewer/score?group=` · `viewer` · `features/viewer/ViewerScorePage.tsx`

## 用途

評審的主要工作頁:選分組 → 逐社團開評分彈窗 → 一邊看資料一邊打分。

## 資料來源

| 動作 | 端點 |
|---|---|
| 指派與社團清單 | `GET /viewer/assignments` |
| 受評資料與既有評分 | `GET /viewer/clubs/{club_id}/awards/{award_id}` |
| 儲存評分 | `PUT /viewer/clubs/{club_id}/awards/{award_id}/score` |

## 畫面

頁首的分組下拉(同獎項有多分組時附分組名區辨),選取寫進 URL `?group=`。

社團表格:社團(附屬性)、評分狀態(已評分(可修改)/ 未評分,另可標「簡報未評」)、合計。前端排序固定「未評分在前 → 社團名升冪」,無排序 UI;前端分頁每頁 20。

點列開 **1000px 雙面板彈窗**:
- 左:受評資料,依細項列出上傳檔案(檔名可點就地預覽,pdf/圖片/docx),未繳交顯示「此項未繳交資料」
- 右:逐細項的分數 InputNumber(0–配分)+ 評語 TextArea(選填);有現場簡報的獎項最後一列是「現場簡報(20)」並註明「選填,可於簡報後補登」;底部固定列顯示合計 / 滿分、上次儲存時間、「儲存」與「儲存並下一社團」

彈窗立即開、內容用 Skeleton,不等網路。

## 規則

- 授權:每次讀取與儲存都驗證該社確實在「我被指派、該獎項」的分組內,否則 403
- **所有評分細項皆為必填**;現場簡報選填
- 儲存是 upsert(唯一鍵 `year+award+club+reviewer`),`review_score_items` 全量替換,`submitted_at` 每次覆寫
- 簡報分只在這次動過時才送(省略=後端維持原值,明給 `null`=清除);其餘欄位為全量取代
- 後端驗證:細項不得重複、不得含不屬於該獎項的項目、不得缺項、分數須在 0–配分之間、簡報分 0–20 且僅 `has_presentation` 的獎項可填
- 「儲存並下一社團」依畫面顯示序**環狀**往下找未評社團(走到底會回頭從第一個找起),整份清單再無未評才關窗
