# 稽核紀錄

`/admin/audit` · `admin`(**僅 super**) · `features/admin/AuditPage.tsx`

> 側欄沒有這一項,入口只有頂欄帳號選單的「稽核紀錄」。

## 用途

高風險操作的軌跡查詢。唯讀。

## 資料來源

`GET /admin/audit?user_id&role&action&page&page_size`(每頁 20)

## 畫面

表格:時間、操作者、角色、動作、內容。操作者 / 角色 / 動作三個漏斗篩選 —— 後端是單值參數,所以漏斗是**單選**(點另一項即切換、再點同一項取消)。

操作者選項從**已載入過的列**累積(id ↔ 姓名對照),沒有獨立的操作者清單端點。

## 規則

- 依時間降冪,`id` 降冪 tiebreak
- 記錄範圍:簽核、帳號與權限異動、密碼重設、停權、社團主檔異動、成員名冊增刪改與匯入、設定變更、規則增刪、檔案刪除(報修、評鑑、活動照片與附件)、評分與行政分調整等
- 帳號刪除後稽核仍保留(`user_id` ON DELETE SET NULL,操作者顯示為空)

## 未完成 / 問題

- 操作者選項只涵蓋「翻過的頁面出現過的人」,沒翻到就篩不到
- 沒有時間區間篩選,也不能匯出
- 稽核軌跡的篩選查詢缺少可用索引
