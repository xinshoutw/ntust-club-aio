# 成員列表(行政端)

`/admin/members` · `admin` · 權限鍵 `amember` · `features/admin/AdminMembersPage.tsx`

## 用途

查閱單一社團的成員名冊並匯出 CSV。**唯讀** —— 名單由社團自行維護。

## 資料來源

`GET /admin/clubs/{club_id}/members?semester&sort&page&page_size`(每頁 50;參數與排序白名單和社團端 `/club/members` 共用同一份實作)

## 畫面

頁首:學期下拉、匯出 CSV、選擇社團。表格:姓名、學號、身份、職稱、電話、學期、更新時間。除電話外皆可多鍵排序(伺服器端)。

## 規則

- 身份顯示詞依所選社團的 `kind` 推導(社團→社長、學會→會長)
- 匯出格式與社團端匯入相容(無標題列、身份用顯示詞)
- 切換社團或學期都會重設回第 1 頁

## 未完成 / 問題

- **學期下拉只有「當前學期」與「全部學期」** —— admin 端沒有 `semesters` 子端點,查不到特定歷史學期的名單
- 沒有身份篩選(社團端有),要找幹部只能靠排序
