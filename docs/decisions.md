# 決策紀錄

需求方(學務處)與系統管理端拍板的規則。**這裡記「為什麼系統是這樣」,不記進度**;
進度看 [`HANDOFF.md`](HANDOFF.md),行為細節看 [`spec/`](spec/)。

一條決策落地後,對應的 `ISS-` / `GAP-` / `DEC-` 編號就從 `issues.md` / `gaps.md` 移除,
但本檔的條目**永久保留** —— 後人問「為什麼不能改成 X」時,答案在這裡。

## 2026-08-18 第一批(決策單第一至三節)

### 權限與帳號

| 編號 | 決策 |
|---|---|
| **D-01** | **每一個側欄頁面各自一個權限鍵**,包含目前 super 專屬的五頁(器材主檔與手動借用、場地不開放規則、逾期追蹤與停權管理、系統設定、稽核軌跡)。管理員可逐頁勾選授權,不再有「只有 super 看得到」的頁面 |
| **D-02** | 檔案下載權限**跟著 D-01 的頁面權限走**,不另立分類。看得到那一頁 = 下載得了那一頁的檔案 |
| **D-11** | 刪掉「線上申請管理」頁,在「其他」類別下獨立成**「證明管理」與「郵局管理」兩頁**,各自一個權限鍵 |
| **ISS-25** | 重設社團密碼歸**「管理項目」**權限,不歸 super |

|---|---|
